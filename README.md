# Baltic Brew

> Часть портфолио: [сайт-портфолио](https://auryxn.github.io/site-admin/) — репозиторий сайта [site-admin](https://github.com/auryxn/site-admin).

> Одностраничный демо-лендинг крафтового бара в Вильнюсе (Каролинишкес).

## Что это

Baltic Brew — статичная промо-страница вымышленного крафтового бара: 12 кранов,
ротирующийся ассортимент, настольные игры и спортивные трансляции. Это
демонстрационный лендинг (в подвале прямо указано, что страница — демонстрация),
сделанный как один HTML-файл без сборки и фреймворков.

Страница на литовском языке (`lang="lt"`) и рассчитана на реальную структуру
сайта бара: витрина ассортимента, рассказ о заведении, галерея, блок для
групповых заказов и контакты с формой бронирования по телефону.

## Что есть на странице

- **Шапка** с навигацией и кнопкой «Rezervuoti».
- **Hero** — название бара, короткое описание, рейтинг и ключевые «фишки»
  (12 кранов, настольные игры, спорт-трансляции).
- **Ant čiaupų** — витрина недельного ассортимента: 4 позиции с типом, крепостью,
  описанием и ценой за объём (лагери, IPA, стауты, сидры).
- **Apie barą** — блок «о баре» с преимуществами.
- **Galerija** — галерея заведения.
- **Групповые заказы** — вечеринки и дни рождения до 30 человек, с телефоном.
- **Kontaktai** — телефон, адрес, часы работы, Facebook.

## Стек

- Один файл **`index.html`**: разметка, стили (`<style>`) и скрипты внутри.
- Шрифты с Google Fonts (Bebas Neue, Inter).
- Изображения — по ссылкам на Unsplash.
- Никакой сборки, зависимостей и бэкенда.

## Запуск

Просто открыть файл `index.html` в браузере двойным щелчком.

Либо поднять локальный сервер из папки проекта:

```bash
python3 -m http.server 8000
# затем http://localhost:8000
```
